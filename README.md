# RiskFlow

> 让复杂的金融风险"看得见"

## 这是什么？

RiskFlow 是一个**交互式金融风险可视化工具**，通过蒙特卡洛模拟将抽象的风险概念转化为直观的图表：

- **价格置信区间** — 未来价格可能的波动范围
- **收益分布直方图** — 盈亏概率一目了然
- **实时风险指标** — VaR、CVaR、赔率等关键数据

## 解决什么问题？

| 传统方式 | RiskFlow |
|---------|----------|
| 看不懂的数学公式 | 动态演化的可视化图表 |
| 静态的历史数据 | 基于历史自动推演未来 |
| 专业软件高门槛 | 浏览器打开即用 |

## 适用场景

- 📈 **个人投资者** — 评估持仓风险，理解"最坏情况"
- 🎓 **金融学习者** — 直观理解蒙特卡洛模拟、VaR 等概念
- 💼 **量化从业者** — 快速原型验证，向非技术人员展示风险
