# RiskFlow 3D - 第一阶段算法范围

## Phase 1 目标
优先完成 4 个核心算法的可视化闭环，确保每个算法具备：
1. 参数输入
2. 时间步推进（或迭代过程）
3. 3D 主视图
4. 指标面板

## 算法清单（冻结）

### 1) Monte Carlo（已进入 Demo）
- 场景：GBM 路径云、风险分布、尾部风险演示。
- 输入：`S0, drift, volatility, years, steps, paths, seed`。
- 核心指标：均值路径、分位数区间、VaR95、ES95、亏损概率。

### 2) Black-Scholes
- 场景：期权定价曲面（标的价格 × 到期时间）。
- 输入：`S, K, r, sigma, T, optionType`。
- 核心指标：价格 + Greeks（Delta, Gamma, Vega, Theta, Rho）。

### 3) Markowitz
- 场景：投资组合有效前沿 3D（收益、波动、Sharpe）。
- 输入：资产收益序列、协方差矩阵、无风险利率、约束条件。
- 核心指标：最小方差点、最大 Sharpe 点、权重分布。

### 4) Kalman Filter
- 场景：观测噪声下的隐变量估计轨迹。
- 输入：状态转移矩阵、观测矩阵、过程噪声、观测噪声、初始状态。
- 核心指标：滤波误差、残差、置信区间。

## 阶段退出标准
- 4 个算法均接入统一可视化引擎接口。
- 每个算法至少提供 1 个可运行 Demo 页面。
- 每个 Demo 支持参数调节与指标实时刷新。
